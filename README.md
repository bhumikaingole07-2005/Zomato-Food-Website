# 🍽️ Zomato Clone

A responsive front-end clone of the Zomato website built using **HTML, CSS, and JavaScript**. This project recreates the look and feel of Zomato with a clean, modern, and user-friendly interface while focusing on responsive web design and front-end development skills.

## 🚀 Features

- Responsive design for all screen sizes
- Modern and attractive UI
- Interactive navigation bar
- Hero section with search functionality
- Restaurant listing cards
- Food categories section
- Offers and promotions section
- Footer with useful links
- Smooth scrolling and hover effects
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome

## 📂 Project Structure

```
Zomato-Clone/
│── index.html
│── css/
│   └── style.css
│── js/
│   └── script.js
│── Web pages
└── README.md
```

## 🎯 Purpose

The purpose of this project is to improve front-end development skills by recreating a real-world website using modern web technologies. It demonstrates responsive design principles, layout structuring, UI development, and clean coding practices.

## 💻 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/zomato-clone.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
